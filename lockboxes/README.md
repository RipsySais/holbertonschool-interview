# Lockboxes

## Description
This project solves the "Lockboxes" problem: given a list of boxes,
each possibly containing keys to other boxes, determine whether all
boxes can be unlocked, starting from box 0 which is always unlocked.

## Files

### 0-lockboxes.py
Contains the function `canUnlockAll(boxes)` which returns `True` if
all boxes can be opened, `False` otherwise.

## Requirements
- Python 3.4.3 on Ubuntu 14.04 LTS
- PEP 8 style (version 1.7.x)
- All files executable and end with a new line
